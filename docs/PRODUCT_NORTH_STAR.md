# CodeCortex Product North Star

CodeCortex is a local developer-intelligence layer for coding agents.

**Know the code. Remember the journey. Control the work. Prove the result.**

The coding agent still codes. CodeCortex supplies deterministic repository evidence, project memory, observed run context, guardrails, and verification through one MCP surface.

## Outcomes

CodeCortex should improve five developer outcomes:

1. **Accuracy** — the agent works from the right code, impact and verification evidence.
2. **Efficiency** — reduce unnecessary discovery, repeated work and avoidable token/context use.
3. **Speed** — reach relevant evidence and a proven result faster.
4. **Clarity** — show what happened, what is known, what is missing and why the current code exists.
5. **Guardrails** — keep repository scope, memory scope, test/proof semantics and remote surfaces explicit.

Supporting principles:

- reuse engineering memory instead of repeatedly rediscovering solved facts;
- keep work proportional to the actual change and risk;
- detect complexity drift rather than rewarding more architecture by default;
- never equate "agent finished" with "engineering proven";
- never fabricate host telemetry, token counts, tests or reasoning.

## Architecture constraint

These outcomes do **not** justify adding an intent classifier, planner swarm, autonomous router, or second coding-agent runtime. Prefer MCP tools, deterministic analysis, bounded adapters, and evidence.
