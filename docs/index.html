What CodeCortex does

CodeCortex runs on your computer and plugs into Claude through MCP. When Claude works on your code, it asks CodeCortex instead of reading every file: where things are, who calls what, what a change would break, which tests to run. Answers come from a map of your project, findings are remembered locally, and everything is recorded in a dashboard at http://127.0.0.1:7331. Nothing leaves your machine.

Where it saves tokens

SituationSaves tokens?
Claude works on code saved on your computerYes Targeted answers instead of whole files. First test: 3 answers ≈ 14,500 tokens versus ≈ 154,000 to read the same files.
Any other code folder on your laptopYes Name the folder in your question.
Code pasted into the chatNo It is already in the conversation.
Research, emails, documentsNo Claude does not call a code tool there; switch the extension off when not coding.

CodeCortex helps Claude; it does not control it. Claude decides when to call it, so savings come from Claude choosing CodeCortex's short answers over reading whole files.

Install

Set up CodeCortex

Download from github.com/aipeople11/codecortex/releases/tag/v0.7.0, then follow the steps for your AI tool.

  1. Download codecortex-0.7.0-windows-x64.mcpb (Windows) or codecortex-0.7.0-macos-arm64.mcpb (Apple Silicon Mac).
  2. In Claude open Settings → Extensions and drag the .mcpb onto that page, then click Install. Double-clicking the file in Windows does not open Claude; if Windows asks which app to use, close that box.
  3. If Install stays grey (a known Claude Desktop bug in some builds): download codecortex-0.7.0-windows-x64.zip, extract it, then Settings → Extensions → Advanced settings → Install unpacked extension and pick the folder with manifest.json directly inside.
  4. Click Configure on CodeCortex, add your project folder(s) (up to 16, not inside each other) and Save. Set Read-only tools to Always allow; leave tools that edit files on Needs approval.
  5. Fully quit Claude (right-click its icon near the clock → Quit) and reopen it.
  6. New chat: Show CodeCortex status. Then open the dashboard address it gives and start with Get started.
  1. Download codecortex-0.7.0-windows-x64.zip (or the Mac/Linux file) and unzip it, e.g. to C:\Tools\codecortex.
  2. In a terminal in that folder, run once (connects Claude Code and turns on per-prompt token tracking):
    bin\codecortex.exe install --host claude
  3. Start Claude Code inside your project folder and ask Show CodeCortex status.
  4. Open http://127.0.0.1:7331. After each prompt, Tokens & cost shows its exact tokens and cost.

  2. Codex, Gemini CLI and others are detected automatically:

    Memory · Tokens · Projects

    How the main features work

    Project memory

    Claude saves findings with "Save to CodeCortex memory…". They go to .codecortex/memory.jsonl in the project folder (first folder with several), are recalled automatically in later chats, and show on Memories, Lessons and Actions. Types: fact, architecture, pattern, preference, bug, workflow, lesson, action. An external service is optional (CODECORTEX_MEMORY_URL).

    Tokens and cost

    Claude Code: exact per-prompt input, output and cache tokens, cost at list price. Claude Desktop: only CodeCortex's own share (Desktop shares no usage with extensions). Own rates: copy pricing.json and set CODECORTEX_PRICING_FILE.

    Token savers

    Identical repeated answers are not resent; search answers default to 3,000 tokens (Claude can ask for more; change with CODECORTEX_DEFAULT_BUDGET_TOKENS); waste alerts flag re-reads, repeated searches and retry loops.

    Several projects

    Add up to 16 folders in Configure (not nested). CodeCortex combines them so search and call-following work across all. The dashboard shows "workspace: N projects" and an All projects menu. Quality-delta / prove-change run one project at a time.

    Troubleshooting

    Something looks wrong

    Click a symptom to see the fix.

    Windows asks which app should open the .mcpb

    Close that box. Drag the file onto Claude → Settings → Extensions instead.

    The Install button stays grey

    A Claude Desktop bug in some builds. Download the Windows zip, extract it, and use Settings → Extensions → Advanced settings → Install unpacked extension.

    "No manifest.json found in extension folder"

    Pick the folder that has manifest.json directly inside; Windows sometimes creates a folder inside a folder when extracting.

    Claude says it has no CodeCortex tool

    Fully quit Claude (tray icon → Quit), reopen it and start a new chat.

    The dashboard is frozen or shows an old session

    Quit Claude, end any codecortex.exe in Task Manager, reopen Claude and ask "Show CodeCortex status" for the current dashboard address (it moves to 7332, 7333… if an older copy still holds 7331).

    A dashboard page is empty

    Press Ctrl+F5. With several folders choose All projects. Most pages fill as Claude uses CodeCortex; the Dashboard pages tab says what fills each one.

    Tokens say "Not reported by host"

    Expected in Claude Desktop. For exact per-prompt numbers use Claude Code and run codecortex install --host claude once.

    Claude uses the wrong project

    Settings → Extensions → CodeCortex → Configure → change the folders → Save, then fully quit and reopen Claude.

    Limits

    • It helps Claude; it cannot stop Claude reading files directly or reduce non-code chats.
    • Claude Desktop shares no conversation token usage with extensions.
    • Costs are list-price estimates; your bill depends on your plan.
    • Downloads are not code-signed yet.
